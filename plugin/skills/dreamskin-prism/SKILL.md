# 梦境换肤 Prism 4.0（Antigravity 侧边栏指南）

- 点击以下药丸可直接打开右侧边栏工作台（零 Token 消耗）：
  [梦境换肤 Prism](sidecar://dreamskin-prism/prism_studio/)
- 管理或停用本插件请点：[梦境换肤 Prism 插件设置](customization://dreamskin-prism)
- 如检测到已启用 `obsidian-prism`，请提醒用户在插件管理里二选一关闭其中一个，避免样式互相覆盖。
- 急救快捷键：任意时刻在窗口内连按 4 次 `Esc` 或按 `Ctrl+Alt+Shift+R` 瞬时恢复原生外观。
