# 梦境换肤 4.0（DreamSkin Prism）全量重构与 Antigravity 适配实施计划

> **For agentic workers:** 按任务顺序严格遵循 TDD 红绿循环推进（`modules/test-driven-development/MODULE.md`），每完成一单立刻勾选 `- [x]`、跑全套单测并独立提交；全部完成后按 `modules/verification-before-completion/MODULE.md` 做全量终验。

**Goal:** 以 `agy-wallpaper-prism v2.0.0` 全量升级重构梦境换肤底座（动态壁纸引擎 + Obsidian Prism 液态玻璃 + 极简双层 Web Studio + 极简原生薄壳 + 单后台仲裁 + 多窗口焦点冻结 + 原图标一键升级），并新增 Google Antigravity 一等公民适配器与原生 Sidecar 插件，最终交付 `v4.0.0` 双平台发布包及本机反重力实机验收。

**Architecture:** 采用「一套单后台引擎（`studio-daemon.mjs`）+ 两种入口（独立 Win/Mac 薄壳 & Antigravity Sidecar）+ 一份共享数据（`%LOCALAPPDATA%\DreamSkin\v4\`）」架构；通过 `prism-bridge.mjs` 把原有 8 家适配器 + 新增 `antigravity` 适配器的语义部件统一编译到 `--prism-*` 光学变量层，并叠加温和 Fail-Open CDP、Boot Canary 与多窗口焦点冻结。

**Tech Stack:** Node.js 22+ ESM（零第三方运行时依赖）、Vanilla ES2020 Browser IIFE（微内核 & Studio UI）、C# .NET Framework 4.8（极简 Windows 薄壳）、PowerShell 5.1 / Node `node:test`。

**Spec:** `文档/柠檬/设计/2026-11-23-梦境换肤4.0-Prism全量重构与反重力适配-设计方案.md`

## Global Constraints
- 零第三方运行时依赖（`package.json` 或生产 `src/` 仅使用 Node 内置模块与系统原生 API）。
- 绝不修改任何目标应用的 `app.asar`、安装目录、签名或 `~/.gemini/config/config.json`。
- 所有开发测试在 `06-梦境换肤/源码` 的 `feat/v4-prism-upgrade` 分支内隔离进行；测试必须通过 `DREAMSKIN_DATA_DIR` 隔离临时目录，零污染真实数据目录。
- 既有 264 条核心回归测试必须持续保持通过（除明确随 4.0 升级口径同步更新的断言外，零静默删测试）。
- Antigravity 插件安装至 `~/.gemini/config/plugins/dreamskin-prism/` 必须采用真实文件拷贝（严禁 NTFS Junction），仅在全套自动化测试全绿后的最终任务中执行。
- 保留 `azwosile/agy-wallpaper-prism`（MIT）与既有第三方组件署名于 `THIRD-PARTY-NOTICES.md`。

## Review Focus
1. **双入口抢锁与死锁自愈**：独立端与 Sidecar 同时启动或上次异常崩溃遗留死 PID 锁文件 → 活锁透明复用不双开，死锁自动原子接管；`restore` 后守护进程 0 次自动回弹（Task 2 / Task 7）。
2. **3.0 老数据损坏/重复迁移与恶意 `.dsskin` 包**：老目录缺失/JSON 损坏/重复触发迁移，以及含 `../` 穿越路径或无 manifest 的 `.dsskin` → 迁移只读幂等跳过坏条目，恶意包拒绝且零落盘（Task 3）。
3. **Antigravity 冲突检测与浏览器挖洞**：本机已启用 `obsidian-prism` 插件，且窗口含 `[data-browser-hole]` → 准确识别冲突给出大白话提示，挖洞同步计算圆角 `clip-path` 不遮挡网页（Task 5 / Task 8）。
4. **多窗口并发动态视频焦点冻结**：3 个桌面应用同时开启视频壁纸并在其间切换焦点或全部最小化 → 任意时刻至多 1 个活跃窗口 `paused=false`，其余立即停帧（Task 2 / Task 7）。
5. **Windows `.lnk` 中文路径、幂等补丁与无损还原**：快捷方式含中文名、已有参数、重复升级或只读目录 → 纯 Node 二进制解析无乱码，追加 `--remote-debugging-port` 幂等不重复，还原精确恢复原始参数（Task 6）。
